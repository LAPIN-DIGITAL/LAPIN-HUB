# Históricos

Esta carpeta conserva documentos, legajos y decisiones que **tuvieron vigencia y fueron reemplazados** durante la evolución de LAPIN DIGITAL.

No representan la situación actual de LAPIN.

Se conservan porque el conocimiento que contienen podría volver a ser útil en el futuro — por ejemplo, para entender por qué se tomó una decisión anterior o para retomar una idea que en su momento no prosperó.

> **No es necesario leer esta carpeta para incorporarse a LAPIN.**  
> El onboarding vigente se encuentra en LAPIN HUB, el Reglamento de Integrantes y el Legajo de Rol correspondiente.

## Por qué "99"

El prefijo `99-` es fijo y no correlativo: mantiene esta carpeta siempre al final del repositorio sin necesidad de renumerarla cada vez que se agregue una nueva sección activa (`03-`, `04-`, etc.) en la raíz de LAPIN HUB.
