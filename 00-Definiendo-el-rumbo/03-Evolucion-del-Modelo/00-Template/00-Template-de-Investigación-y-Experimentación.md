# LAPIN | Template de Investigación y Experimentación

## Objetivo

Este template establece la estructura utilizada por LAPIN DIGITAL para documentar investigaciones, experimentos y aprendizajes.

Una investigación no se crea simplemente porque exista información interesante para documentar.

Debe existir un **punto de partida concreto** que genere una pregunta que LAPIN necesite responder.

El objetivo es conservar no solamente la conclusión obtenida, sino también **qué originó la investigación, qué evaluamos, qué descubrimos y por qué tomamos una determinada decisión**.

---

# 1. Punto de partida

Explicar qué ocurrió para que LAPIN comenzara a investigar este tema.

El punto de partida puede ser:

- un problema;
- una necesidad;
- una limitación detectada;
- una nueva capacidad disponible;
- una duda;
- una oportunidad de mejora;
- un resultado inesperado;
- información nueva que necesite ser evaluada.

Debe quedar claro **qué hizo que LAPIN se detuviera a analizar este tema**.

---

# 2. Pregunta de investigación

Definir concretamente qué necesitamos descubrir, comprobar o resolver.

> **Pregunta:** [Pregunta que buscamos responder.]

La investigación debe intentar responder esta pregunta.

Si durante el trabajo aparecen preguntas diferentes que requieren una investigación propia, deben evaluarse separadamente para evitar mezclar temas.

---

# 3. Investigación / Experimentación

Documentar qué hicimos para intentar responder la pregunta.

Puede incluir:

- alternativas consideradas;
- pruebas realizadas;
- comparaciones;
- herramientas evaluadas;
- criterios utilizados;
- limitaciones encontradas;
- errores;
- resultados inesperados;
- observaciones relevantes.

No es necesario registrar cada acción realizada.

Debe conservarse aquello que permita comprender **cómo llegamos desde la pregunta hasta el aprendizaje**.

---

# 4. Qué descubrimos

Registrar la información nueva obtenida durante la investigación.

Los hallazgos pueden:

- confirmar una hipótesis;
- contradecirla;
- mostrar una limitación;
- revelar una alternativa mejor;
- generar una nueva necesidad;
- demostrar que todavía no existe información suficiente para decidir.

Los resultados negativos también deben conservarse cuando aporten conocimiento.

---

# 5. Conclusión

Responder la pregunta planteada al comienzo de la investigación.

La conclusión debe surgir de lo observado y experimentado.

No debe reconstruirse la historia como si LAPIN hubiera conocido la respuesta desde el principio.

Cuando la evidencia todavía no permita obtener una conclusión, debe indicarse claramente.

---

# 6. Decisión adoptada

Registrar qué cambió en LAPIN como consecuencia de la investigación.

La decisión puede ser:

- incorporar algo;
- descartar algo;
- modificar una forma de trabajo;
- mantener el modelo actual;
- crear o modificar una regla;
- realizar una nueva investigación;
- continuar experimentando;
- no realizar cambios.

Cuando corresponda, indicar también qué documentos, procesos, herramientas o componentes fueron afectados por la decisión.

---

**Estado:** [Cerrada / En experimentación / Pendiente de validación]

**Decisión vigente:**  
[Resumen breve de la decisión actualmente adoptada.]

**Revisar cuando:**

# Criterios documentales

Cada investigación debe desarrollar **un tema claramente delimitado**.

Debe aplicarse el principio:

> **Una definición → una fuente.**

Si un conocimiento ya se encuentra desarrollado y mantenido en otro documento, debe referenciarse en lugar de volver a explicarlo.

La cantidad de documentos no constituye un problema cuando cada uno contiene conocimiento diferente y posee una responsabilidad clara.

La duplicación debe evitarse porque genera:

1. **Mantenimiento:** una modificación obliga a actualizar múltiples documentos.
2. **Contradicción:** una copia puede quedar desactualizada y contradecir otra.
3. **Pérdida de fuente de verdad:** deja de estar claro cuál definición se encuentra vigente.

También debe evitarse el extremo contrario: concentrar temas diferentes dentro de un único documento solamente para reducir la cantidad de archivos.

> **Un tema claramente delimitado → un lugar responsable de mantenerlo.**

---

# Instrucción para generar una investigación

A partir de la información proporcionada, documentar la investigación utilizando este template.

El documento debe:

- utilizar lenguaje simple y directo;
- contar la investigación como un proceso y no solamente presentar la conclusión;
- explicar claramente qué situación originó la investigación;
- formular la pregunta que necesitábamos responder;
- registrar las alternativas o pruebas relevantes;
- diferenciar observaciones, aprendizajes y conclusiones;
- conservar errores y resultados negativos cuando aporten conocimiento;
- explicar qué decisión tomó LAPIN como consecuencia;
- indicar si la decisión continúa en experimentación o puede necesitar una revisión futura;
- evitar repetir conocimiento desarrollado en otros documentos;
- referenciar la fuente correspondiente cuando una definición ya exista;
- evitar agregar información solamente para completar el template.

El objetivo es que una persona pueda leer el documento posteriormente y comprender:

> **Qué ocurrió → qué nos preguntamos → qué hicimos → qué descubrimos → qué concluimos → qué decidimos.**
